# Структуры и методы

## Цели

Научиться моделировать данные предметной области структурами, связывать с ними поведение через `impl` и выбирать способ получения `self`. Отдельная цель — не дать вызывающему коду случайно создать некорректное обращение.

## Три формы struct

Именованная структура задаёт поля:

```rust
struct Category {
    code: String,
    display_name: String,
}
```

Tuple struct имеет позиционные поля и отдельный номинальный тип: `struct UserId(u64);`. Он полезен, чтобы не перепутать два `u64` разного смысла. Unit struct `struct Marker;` не содержит данных и может обозначать состояние или реализацию трейта.

Экземпляр создаётся с помощью имени структуры и значений полей. Сокращение field init shorthand позволяет писать `Category { code, display_name }`, если переменные называются так же. Struct update syntax `..other` перемещает или копирует оставшиеся поля и влияет на владение исходной структурой.

## Владение полями

Структура владеет своими `String`, если поле имеет тип `String`. Можно переместить структуру целиком, а в некоторых контекстах — отдельное поле. После частичного move нельзя использовать всю структуру, хотя неперемещённые поля могут оставаться доступными.

```rust
struct Draft {
    title: String,
    rating: u8,
}

let draft = Draft { title: String::from("Idea"), rating: 4 };
let title = draft.title;
println!("{}", draft.rating);
// draft целиком больше недоступен
```

Ссылка `&draft.title` лишь заимствует поле и не вызывает move.

## Блок impl

Методы и associated functions объявляются в `impl Type`:

```rust
impl Category {
    fn new(code: String, display_name: String) -> Self {
        Self { code, display_name }
    }

    fn label(&self) -> String {
        format!("{}: {}", self.code, self.display_name)
    }
}
```

`Self` обозначает тип текущего `impl`. Associated function не принимает `self` и вызывается `Category::new(...)`. Метод вызывается через точку и имеет специальный первый параметр.

Можно иметь несколько блоков `impl`, но группировка должна оставаться логичной. Поля и методы не обязаны находиться в одном файле с вызывающим кодом; видимость модулей будет в уроке 12.

## self, &self и &mut self

- `&self` читает объект, не отбирая владение; подходит для предикатов и вычислений;
- `&mut self` разрешает изменить объект, сохраняя владельца прежним;
- `self` потребляет объект; подходит для перехода в другой тип или извлечения owned-поля;
- `&mut self` не означает, что метод обязан менять все поля.

Компилятор автоматически добавляет ссылку при вызове метода. В сигнатуре нужно выбирать минимально необходимый доступ: `self` только ради чтения делает API менее удобным.

## Инварианты и конструктор

Если любой `u8` технически помещается в `rating`, тип сам по себе не гарантирует диапазон 1–5. Конструктор может проверить вход и вернуть `Result<Feedback, String>`:

```rust
let draft = Feedback::new(1, String::from("Title"), 5);
assert!(draft.is_ok());
```

`Result` здесь используется как «успех или ошибка»; подробный разбор будет в уроке 07, а `String` ошибки позже мы заменим содержательным enum. Метод `is_ok()` лишь проверяет успешность.

Инвариант сохраняется только при дисциплине API. В учебной структуре поля оставлены публичными для исследования, но реальный тип часто делает поля приватными и предоставляет проверенные методы. Даже с публичными полями ваши методы обязаны соблюдать контракт.

## Мутация и ошибки

Метод `update_rating` должен сначала проверить новое значение и лишь затем менять объект. Если изменить поле, а потом вернуть `Err`, объект останется в неожиданном состоянии. Такой порядок особенно важен, когда метод меняет несколько полей или обращается к внешней системе.

## derive

`#[derive(Debug, Clone, PartialEq, Eq)]` генерирует реализации стандартных трейтов:

- `Debug` — форматирование для диагностики;
- `Clone` — явное создание копии;
- `PartialEq`/`Eq` — сравнение.

Derive не делает структуру автоматически `Copy`: наличие `String` этому препятствует. Не добавляйте все доступные derive без потребности.

## Типичные ошибки

- принимать `self` там, где нужен `&self`;
- пытаться вызвать associated function через точку;
- менять объект до проверки входа;
- считать `Clone` бесплатным или автоматическим;
- оставлять ошибку без содержательного сообщения.
