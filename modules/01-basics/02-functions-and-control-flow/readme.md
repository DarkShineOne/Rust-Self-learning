# Функции, выражения и управление потоком

## Цели

Научиться строить функции из выражений, выбирать подходящий цикл и не путать значение с инструкцией. Это первый урок, где компилятор проверяет не только типы, но и наличие результата на каждом пути.

## Инструкции и выражения

Инструкция выполняет действие и не возвращает полезного значения. Выражение вычисляет значение. `let` и определение функции являются инструкциями, а точка с запятой превращает выражение в инструкцию. Литералы, вызовы, блоки и `if` могут быть выражениями.

```rust
let category = {
    let score = 7;
    if score >= 5 { "important" } else { "normal" }
};
```

Ветки выражения `if` должны иметь совместимый тип. Точка с запятой после последнего значения блока превращает его в инструкцию и часто приводит к ошибке «ожидался тип, найден `()`».

`()` — unit type, значение «ничего содержательного». Функция без указанного возвращаемого типа возвращает `()`.

## Функции и возврат

```rust
fn double(value: i32) -> i32 {
    value * 2
}
```

Последнее выражение возвращается без `return`. Ранний `return` полезен для выхода из середины функции, но обычный результат в конце принято писать без него.

Имя функции и параметры образуют её тип. Сигнатура не содержит реализации и позволяет вызывать код независимо от того, написан он ниже или в другом модуле.

## Условия

`if` требует именно `bool`: Rust не считает число или строку истинными. `else if` формирует цепочку, а `else` обязателен, если результат `if` используется как значение и компилятор должен гарантировать его наличие.

```rust
if rating >= 4 {
    println!("positive");
} else if rating == 3 {
    println!("neutral");
} else {
    println!("negative");
}
```

Сложный разбор перечислений позже удобнее выразить через `match`.

## Циклы

- `loop` повторяется без встроенного условия и может вернуть значение через `break value`;
- `while` проверяет условие перед итерацией;
- `for` перебирает значения, полученные из итератора.

```rust
let mut attempts = 0;
while attempts < 3 {
    attempts += 1;
}

for rating in 1..=5 {
    println!("{rating}");
}
```

Диапазон `1..5` исключает 5, а `1..=5` включает. `for` обычно безопаснее ручного индексирования: меньше возможностей выйти за границы и пропустить элемент.

`break` завершает ближайший цикл, `continue` начинает следующую итерацию. Метки `'outer: loop` помогают при вложенных циклах, но часто вынесение функции делает код понятнее.

## Переполнение и инварианты

Даже простой счётчик требует выбора типа. Если вход `u64`, не преобразуйте его в `u32` без причины. В домашнем задании последовательность Collatz считается для небольших учебных значений, но реализация должна явно поддерживать чётные и нечётные числа и стартовую единицу.

Не добавляйте бесконечный `loop`, если условие естественно записывается через `while`. Инструмент должен отражать инвариант: «повторять, пока значение не равно единице».

## Типичные ошибки

- ставить `;` после возвращаемого выражения;
- использовать число как условие `if`;
- возвращать из веток разные типы строк без преобразования;
- путать включённую и исключённую границу диапазона;
- проверять `n % 3` и `n % 5` так, что случай делимости на 15 никогда не достигается.
