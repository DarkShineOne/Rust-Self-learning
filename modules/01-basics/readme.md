# Модуль 1. Базовый Rust

Модуль строит модель владения и типов Rust до перехода к фреймворкам. Сначала рассматриваются выражения и базовые типы, затем ownership/borrowing, моделирование через struct/enum, ошибки и коллекции. Generics, traits и lifetimes изучаются после практических задач, где абстракции действительно нужны. В конце — разделяемое состояние, async и консольный CRUD.

## Результат

После модуля студент должен уметь:

- создавать библиотеки и приложения Cargo;
- проектировать API с учётом владения и заимствования;
- использовать `Option` и `Result` вместо null и исключений;
- моделировать предметную область типами и инвариантами;
- работать с коллекциями, итераторами и трейтами;
- разделять код на модули и писать unit/integration/doc tests;
- выбирать между owned-данными, ссылками и умными указателями;
- безопасно применять Tokio и разделяемое состояние;
- реализовать и протестировать консольный CRUD обратной связи.

Не пытайтесь обходить borrow checker массовыми `.clone()`. Сначала определите, кто владеет данными и как долго нужна ссылка.
