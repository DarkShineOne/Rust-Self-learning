# Домашнее задание: ссылки и срезы

Реализуйте три функции в `src/lib.rs`:

```rust
pub fn first_word(text: &str) -> &str;
pub fn sum_slice(values: &[i32]) -> i64;
pub fn clamp_all(values: &mut [i32], min: i32, max: i32);
```

## Контракт

- `first_word` возвращает срез исходной строки до первой последовательности Unicode whitespace. Начальные пробелы пропускаются. Если слова нет, вернуть `""`. Нельзя выделять новый `String`: тесты сравнивают указатель результата с позицией внутри входа.
- `sum_slice` суммирует в `i64`, пустой срез даёт 0. Не переполняйте промежуточную сумму `i32`.
- `clamp_all` заменяет каждое значение меньше `min` на `min`, больше `max` на `max`; остальные значения и длина среза не меняются. Гарантируется `min <= max`, пустой срез допустим.

Сохраняйте заимствование в сигнатурах. Не решайте задание через клонирование всего входа.
