# Владение

## Цели

Понять, почему передача `String` в функцию может запретить дальнейшее использование переменной, когда происходит копирование и как вернуть владение вызывающему коду. Это центральное отличие Rust от языков с неявно разделяемыми изменяемыми объектами.

## Три правила

1. У каждого значения есть владелец.
2. В один момент времени владелец один.
3. Когда владелец выходит из области видимости, значение освобождается через `drop`.

Владение позволяет компилятору освобождать память без сборщика мусора и одновременно предотвращать double free/use-after-free.

## Стек, куча и String

Число `u64` имеет фиксированный размер и обычно размещается непосредственно в стековом фрейме. `String` — владеющая структура с буфером в куче: сама структура содержит указатель, длину и ёмкость.

```rust
let first = String::from("feedback");
let second = first;
// println!("{first}"); // значение перемещено в second
println!("{second}");
```

Присваивание перемещает владение. Копировать указатель и оставить обе переменные действующими было бы опасно: обе попытались бы освободить один буфер. Поэтому Rust делает move и запрещает старую привязку.

Не представляйте move как обязательное физическое копирование байтов или перемещение кучи. Буфер строки остаётся на месте; меняется ответственность за него.

## Copy и Clone

Типы, целиком содержащиеся в своём значении и реализующие `Copy`, копируются при присваивании: целые, `bool`, `char`, `f64`, кортежи из `Copy`-значений.

`String` не реализует `Copy`. Если нужны два независимых владельца одного текста, используется явный `.clone()`, который копирует буфер.

```rust
let original = String::from("idea");
let backup = original.clone();
println!("{original} / {backup}");
```

Clone — не универсальный ответ borrow checker. Он создаёт копию данных и имеет стоимость. Часто лучше передать ссылку или вернуть владение.

## Функции и move

Передача owned-параметра перемещает значение в функцию:

```rust
fn shout(mut text: String) -> String {
    text.push('!');
    text
}

let input = String::from("hello");
let output = shout(input);
// input больше недоступен, output владеет строкой
```

Возврат `String` передаёт владение обратно. Кортеж позволяет вернуть значение вместе с вычисленными метаданными. Если функция должна только прочитать текст, owned `String` в сигнатуре обычно избыточен; в уроке 04 появится `&str`.

## Области видимости

При выходе из блока локальные владельцы освобождаются в обратном порядке создания. Значение можно вернуть из блока, иначе его буфер будет освобождён:

```rust
let message = {
    let local = String::from("created inside");
    local
};
```

Здесь владение перемещено наружу, поэтому `drop` строки не произошёл в конце внутреннего блока.

## Размер и длина текста

`String::len()` возвращает число UTF-8 байтов, не символов. Например, длина `"ё"` равна двум байтам. Это важно для домашнего контракта: требуется именно длина в байтах.

`trim()` возвращает заимствованный `&str` без краевых пробелов. `to_uppercase()` создаёт новый `String`, поскольку Unicode-преобразование может изменить длину. Подробности UTF-8 будут в уроке 08.

## Типичные ошибки

- ожидать, что `String` ведёт себя как `i32`;
- клонировать каждое значение «на всякий случай»;
- принимать `String`, если функция лишь читает текст;
- считать `.clone()` неглубоким копированием указателя;
- путать байты и символы при вычислении длины.
