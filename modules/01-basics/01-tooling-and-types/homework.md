# Домашнее задание: вычисления и базовые типы

Реализуйте функции в `src/lib.rs`. Тела содержат `todo!()`, сигнатуры менять не нужно.

## Публичный контракт

```rust
pub fn celsius_to_fahrenheit(celsius: f64) -> f64;
pub fn fahrenheit_to_celsius(fahrenheit: f64) -> f64;
pub fn average_rating(ratings: &[u8]) -> f64;
```

- Температуры переводятся по стандартным формулам: `F = C × 9 / 5 + 32`, `C = (F − 32) × 5 / 9`.
- `average_rating` возвращает арифметическое среднее как `f64`.
- Для пустого среза среднее равно `0.0`.
- Входные оценки принадлежат `1..=5`; дополнительную валидацию в этом задании выполнять не требуется.
- Сумма должна вычисляться без переполнения `u8`; не используйте целочисленное деление для результата.
