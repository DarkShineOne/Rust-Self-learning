# Инструменты, Cargo, переменные и примитивные типы

## Цели

После урока вы сможете создать библиотеку Cargo, отличать переменную от значения и выбирать базовые числовые типы. Предполагается, что переменные и функции знакомы по другим языкам; здесь важны именно различия Rust.

## Rust и Cargo

`rustc` компилирует отдельную программу, а Cargo управляет пакетом: зависимостями, сборкой, тестами и документацией. Обычно напрямую вызывать `rustc` не нужно.

```bash
cargo new my_library --lib
cargo test
cargo fmt
cargo clippy
```

Пакет содержит `Cargo.toml` и один или несколько crate. `src/lib.rs` — корень библиотечного crate, `src/main.rs` — бинарного. Наша заготовка является библиотекой: интеграционные тесты обращаются к её публичным функциям.

## Переменные и неизменяемость

```rust
let category = "idea";
let mut rating = 3;
rating += 1;
```

`let` по умолчанию создаёт неизменяемую привязку. `mut` разрешает присвоить новое значение той же привязки, но не меняет её тип. Неизменяемость здесь не означает «константу во время компиляции»: значение `let` может вычисляться во время выполнения.

Имя можно затенить повторным `let`. Shadowing создаёт новую привязку и позволяет изменить тип; `mut` этого не делает.

```rust
let count = "4";
let count: u32 = count.parse().expect("корректное учебное значение");
```

`expect` в примере допустим потому, что вход фиксирован. Для пользовательского ввода ошибку нужно обработать — этому посвящён урок 07.

## Скалярные типы

- целые: `i8`…`i128`, `u8`…`u128`, зависимые от платформы `isize`/`usize`;
- числа с плавающей точкой: `f32`, `f64`;
- логический `bool`;
- символ Unicode `char`, который не равен одному байту.

Rust не складывает неявно `u8` и `f64`. Преобразование выполняется через `as` или проверяемые методы `From`/`TryFrom`. У `as` есть правила округления и возможной потери точности, поэтому выбирайте его осознанно.

```rust
let votes = 12_u32;
let average = votes as f64 / 4.0;
```

В debug-сборке целочисленное переполнение обычно вызывает panic. Не рассчитывайте на сохранение этого поведения в release-сборке: для бизнес-правил лучше выбирать достаточный тип и проверять вход.

## Кортежи и массивы

Кортеж объединяет фиксированное число значений, возможно разных типов:

```rust
let feedback: (u64, &str, bool) = (7, "Нужна тёмная тема", false);
let id = feedback.0;
```

Массив `[T; N]` хранит `N` значений одного типа. Его длина является частью типа. Срез `&[T]` — заимствованное представление последовательности, длина которого известна во время выполнения. Подробно срезы и заимствование разбираются в уроке 04; сейчас достаточно передавать `&ratings`.

```rust
let ratings = [5, 4, 4];
let slice: &[u8] = &ratings;
assert_eq!(slice.len(), 3);
```

Для коллекции переменной длины позже появится `Vec<T>`, а для текста — `String`.

## Функции и вывод типов

Типы параметров и возвращаемого значения функции указываются явно. Тип локальных переменных компилятор часто выводит сам. Публичная сигнатура — документация и стабильный контракт, поэтому не стоит полагаться в ней на вывод.

В следующем уроке вы увидите, почему последнее выражение функции обычно пишут без `return` и точки с запятой.

## Типичные ошибки

- прибавлять `1` к неизменяемой переменной вместо явного `mut`;
- ожидать неявного числового преобразования;
- сравнивать `f64` без допуска;
- путать `char` и UTF-8 байт;
- вызывать `rustc` там, где нужен Cargo с зависимостями и тестами.
